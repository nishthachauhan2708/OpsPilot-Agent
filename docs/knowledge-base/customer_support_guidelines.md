# UrbanCart Customer Support & Operations Guidelines

## 1. Tone and Communication Tone
- Always maintain an empathetic, professional, transparent, and solution-oriented tone.
- Acknowledge customer inconvenience directly when delays or damaged items occur.
- State clear order reference numbers, dates, and actionable resolution steps.

## 2. Customer Message Templates & Protocols
- **Delayed Delivery Message**: State current location, carrier status, updated delivery estimate, and apology.
- **Damaged Item Message**: Express regret, offer instant replacement or return option, explain easy approval process.
- **Return Approved Message**: Provide return shipping instructions and expected refund timeframe.
- **Return Rejected Message**: Explain clear policy reason (e.g. outside 7-day window) with polite alternative support options.

## 3. Human Approval Safeguards
- Any action modifying order status, issuing store credit, creating return requests, or sending customer messages must generate a transparent audit entry.
- Write actions must be submitted to the Operations Action Queue for human sign-off.
