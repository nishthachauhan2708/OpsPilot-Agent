# UrbanCart Return Policy

## 1. Overview
At UrbanCart, customer satisfaction is our priority. This return policy governs all items purchased through UrbanCart platforms.

## 2. Standard Return Window
- Standard merchandise can be returned within **7 calendar days** from the date of confirmed delivery.
- Items must be in original, unused condition with all tags, original packaging, manuals, and accessories intact.

## 3. Damaged or Defective Items
- Items received damaged, defective, or incorrect must be reported within **48 hours** of delivery.
- Photographic evidence or video proof of damage during unboxing may be requested by customer support.
- Damaged items are eligible for full replacement or immediate return request regardless of standard category return restrictions.

## 4. Non-Returnable Categories
- Final sale or clearance items marked "Non-Returnable".
- Perishable goods, personal hygiene items, and opened software/digital products.
- Customized or personalized merchandise.

## 5. Return Eligibility Criteria
An order is eligible for return if:
1. The return request date is within the 7-day window (or 48 hours for damaged items).
2. The order status is `delivered`.
3. No prior return request for the same order is currently `active` or `completed`.
4. The product category permits return.

## 6. Return Request Process
1. Returns must be initiated via OpsPilot or Customer Support portal.
2. Once a return request is submitted, it enters a `pending_approval` state.
3. Operations team or OpsPilot Agent approves the request, generating a prepaid return shipping label.
4. Once returned items arrive at the warehouse and undergo inspection, refund processing is initiated.
